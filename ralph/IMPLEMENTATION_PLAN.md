## Phase 2: Identity Inspector

- [x] Person selector + confidence breakdown + keyframe table + CRUD: `views/identity_inspector.py` — QComboBox person selector with inactive track filtering, ConfidenceTimeline embed, 6 QLabels for confidence breakdown (detection/visibility/overlap/shape/motion/overall with color coding), QTableWidget keyframe table (Frame/Verified/Confidence/BBox/Actions columns with Go/Del buttons), keyframe CRUD (add/remove/verify/prev/next navigation), signal hub (person_changed/frame_requested/keyframe_changed/bbox_overlay_changed). Wired to Session.person_tracks via PersonTrack.keyframes (serialized) and PersonTrack.confidence_breakdown (runtime). MultiPersonTab placeholder replaced, signals connected for frame sync + person selection. Tests in `tests/test_identity_inspector.py` (241 total pass).
- [x] Bbox overlay rendering: `views/bbox_overlay.py` — pure function `render_bbox_overlay()` draws all tracked person bboxes on video frames using cv2. Color-coded by person (PERSON_COLORS), person ID labels with confidence badge, dashed outlines for corrected bboxes, solid for originals. Inactive tracks shown as dashed gray when show_all_tracks=True. Composited onto VideoPlayer in `MultiPersonTab._show_frame()`. Signal wiring: identity_panel.bbox_overlay_changed → show_all toggle, person_changed → redraw, keyframe_changed → redraw. Tests in `tests/test_bbox_overlay.py` (278 total pass).
- [x] Two-click bbox editing: `views/identity_inspector.py` — state machine (idle → click1 → click2 → idle), normalized-to-pixel coordinate mapping via `on_frame_click()`, bbox correction storage with min-size enforcement (20px) and image clamping, automatic keyframe creation, dirty person marking. Edit/Cancel buttons toggle state. Interpolate button for delta-space linear interpolation between corrected keyframes via `interpolate_bbox_corrections()`. Apply All button saves corrections to `person_dir/bbox_corrections.json`. Crosshair preview at corner1 via `render_edit_preview()` in `bbox_overlay.py`. MultiPersonTab wires `frame_clicked → on_frame_click`, stores `edit_preview` state for overlay compositing. Tests in `tests/test_bbox_editing.py` (335 total pass).
- [x] Track operations: `views/identity_inspector.py` — swap IDs (QComboBox target + button, swaps bboxes/confidences/corrections from current frame onward, adds verified keyframes, marks dirty), split track (creates new inactive PersonTrack from frame_idx onward, zeros original after split, splits keyframes/corrections), merge track (QComboBox inactive source + button, non-zero frames overwrite target, removes source, merges keyframes), crossing span marking (Mark Start/Mark End two-click workflow with status label, stored in Session.crossing_spans dict[pid → list[(start, end)]], table display with Del buttons). Show all tracks checkbox already implemented. Session.crossing_spans changed from list[tuple] to dict[int, list[tuple[int, int]]]. `track_modified` signal wired to MultiPersonTab._on_tracks_modified for refresh. Tests in `tests/test_track_operations.py` (407 total pass).
- [x] Review scanner + reprocess: `views/identity_inspector.py` — `ReviewIssue` dataclass + `compute_review_issues()` function scans all active tracks for 4 issue types: low_confidence (spans ≥5 frames below 0.4, severity 0.7), potential_swap (overlap >0.5, severity 0.9), shape_drift (shape confidence <0.4, severity 0.6), track_gap (zero-bbox gaps ≥30 frames, severity 0.5). Scanner UI group: Scan button, Prev/Next issue navigation (wrapping), issues QTableWidget (Frame/Person/Type/Description), status label with [idx/total] format, double-click row to navigate. Reprocess button shows dirty count, emits `reprocess_requested(list)`, wired to `MultiPersonTab._on_reprocess_requested` which launches `ReprocessWorker` with progress/person_done/finished/error signals. Worker completion clears dirty_persons and refreshes all panels. `update_reprocess_button()` auto-called on person_dirty signal. Tests in `tests/test_review_scanner.py` (449 total pass).

## Phase 3: 3D Viewport + Pose Corrector

- [x] QOpenGLWidget mesh viewport: `views/mesh_viewport.py` — MeshViewport(QOpenGLWidget) with graceful degradation when PyOpenGL unavailable (falls back to QWidget label). Lazy SMPL-X model loading via SmplxLite from backend, per-frame vertex computation (torch forward → numpy) with LRU cache (200 entries), per-vertex normal computation, VBO upload (position/normal/color + static EBO), Phong shading using existing shaders/mesh.vert + mesh.frag. Camera projection from session camera_K or estimated K via k_to_projection() with CV→GL coordinate flip. Pure helper functions: compute_normals(), k_to_projection(), estimate_K(). Integrated into MultiPersonTab replacing placeholder — wired to frame_changed, person_selected, track_clicked signals. Tests in `tests/test_mesh_viewport.py` (500 total pass).
- [x] Camera modes: `views/mesh_viewport.py` — in-camera mode using K_fullimg intrinsics (existing k_to_projection), free orbit mode with mouse controls (left drag=orbit, middle drag=pan, scroll=zoom, double-click=reset). Pure helper functions `compute_orbit_view()` (spherical look-at matrix) and `perspective_fov()` (symmetric FOV projection). Orbit state: yaw/pitch/distance/center with auto-centering on mesh centroid (CV→GL coordinate flip). Model matrix set to _CV_TO_GL in orbit mode so orbit operates in GL space. Mode-aware `_update_projection()` switches between K-based and FOV-based projection. `camera_changed` signal emitted on all camera state changes. Tests in `tests/test_mesh_viewport.py` (544 total pass).
- [ ] Skeleton overlay + joint picking: draw bones as GL_LINES from FK joint positions, draw joints as GL_POINTS. Reference: `visualize_skeleton.py:forward_kinematics`, `BONE_CONNECTIONS`, `JOINT_NAMES`. `pose_correction.py:compute_skeleton_frame`, `find_nearest_joint`.
