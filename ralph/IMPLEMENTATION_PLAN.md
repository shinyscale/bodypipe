# bodypipe — Implementation Plan

## Phase 1: Pipeline Tabs

- [x] Single-person tab: `views/single_person_tab.py` — drag-drop + browse video input with thumbnail/info, settings group (static_cam, use_dpvo, focal_mm), run/cancel wired to GVHMRWorker, progress bar, output file list with context menus, VideoPlayer preview. AppWindow tab 1 replaced. Tests in `tests/test_single_person_tab.py` (85 total pass).
- [x] Performance capture tab: `views/perf_capture_tab.py` — subclasses SinglePersonTab, adds hand capture group (enable + hybrid/SMPLest-X radios), face capture checkbox. Wired to FullPipelineWorker. AppWindow tab 2 replaced. Tests in `tests/test_perf_capture_tab.py` (105 total pass).
- [x] Multi-person tab shell: `views/multi_person_tab.py` — left sidebar with video input/pipeline settings/multi-person settings (max_persons, confidence_threshold), main viewport with VideoPlayer, vertical+horizontal QSplitters for identity inspector and pose corrector placeholders, TrackOverview with per-person ConfidenceTimeline bars, signal hub wiring frame_changed/person_selected across sub-panels, MultiPersonWorker integration. AppWindow tab 3 replaced. Tests in `tests/test_multi_person_tab.py` (167 total pass).

## Phase 2: Identity Inspector

- [x] Person selector + confidence breakdown + keyframe table + CRUD: `views/identity_inspector.py` — QComboBox person selector with inactive track filtering, ConfidenceTimeline embed, 6 QLabels for confidence breakdown (detection/visibility/overlap/shape/motion/overall with color coding), QTableWidget keyframe table (Frame/Verified/Confidence/BBox/Actions columns with Go/Del buttons), keyframe CRUD (add/remove/verify/prev/next navigation), signal hub (person_changed/frame_requested/keyframe_changed/bbox_overlay_changed). Wired to Session.person_tracks via PersonTrack.keyframes (serialized) and PersonTrack.confidence_breakdown (runtime). MultiPersonTab placeholder replaced, signals connected for frame sync + person selection. Tests in `tests/test_identity_inspector.py` (241 total pass).
- [ ] Bbox overlay rendering: draw all tracked person bboxes on video frames with person ID labels, color-coded by person, dashed outline for corrected bboxes. Composite overlay onto VideoPlayer via set_frame(). Reference: `identity_panel.py:_render_frame_with_bboxes`, `_get_bboxes_at_frame`.
- [ ] Two-click bbox editing: click frame for top-left corner, click again for bottom-right, show dashed preview rectangle during edit. Interpolate button for linear bbox interpolation between keyframes. Apply button to commit corrections to disk. Cancel button to abort. Coordinate mapping from normalized VideoPlayer click coords to pixel coords. Reference: `identity_panel.py:on_frame_click`, `on_interpolate_bboxes`, `on_apply_keyframes`, `_save_bbox_corrections`.
- [ ] Track operations: swap IDs (dropdown + button), split track at current frame, merge track into target, crossing span marking (start/end buttons + table display). Show all tracks checkbox for multi-person overlay. Reference: `identity_panel.py:on_swap_ids`, `on_split_track`, `on_merge_track`, `on_crossing_start`, `on_crossing_end`. Backend: `identity_bridge.py:crossing_spans_from_signal`.
- [ ] Review scanner + reprocess: scan button auto-detects issues (low confidence, missing keyframes, large gaps), issues table with prev/next navigation that seeks to problem frames. Reprocess button shows count of dirty persons, triggers ReprocessWorker, reloads results into Session. Reference: `identity_panel.py:on_scan_issues`, `on_next_issue`, `on_reprocess_all_dirty`. Backend: `multi_person_split.py:reprocess_person`.

## Phase 3: 3D Viewport + Pose Corrector

- [ ] QOpenGLWidget mesh viewport: load SMPL-X body model once, compute per-frame vertices from params (torch forward pass → numpy), upload to VBO, render with Phong shading via shaders/mesh.vert + mesh.frag. Static draw for first frame as proof of concept. Reference: `multi_person_split.py:render_multi_person_incam()` for vertex computation, `visualize_skeleton.py:forward_kinematics()`.
- [ ] Camera modes: in-camera mode using K_fullimg intrinsics for perspective projection matching video, free orbit mode with mouse controls (left drag=orbit, middle drag=pan, scroll=zoom, double-click=reset). Frame scrubbing updates mesh vertices per frame. Cache vertices when params unchanged. Reference: `visualize_skeleton.py:_get_projection_intrinsics`, `project_to_2d`. `pose_correction_panel.py:_camera_space_params`.
- [ ] Skeleton overlay + joint picking: draw bones as GL_LINES from FK joint positions, draw joints as GL_POINTS. Click-to-select joint via screen-space distance (project joints to screen, find nearest within 20px threshold). Emit joint_clicked(int) signal. Highlight selected joint in accent color. Reference: `visualize_skeleton.py:forward_kinematics`, `BONE_CONNECTIONS`, `JOINT_NAMES`. `pose_correction.py:compute_skeleton_frame`, `find_nearest_joint`.
- [ ] Pose corrector joint controls: person selector (QComboBox), joint selector (QComboBox with all SMPL-X joints, also set via viewport click), 3 euler sliders (QSlider + QDoubleSpinBox, range -180 to 180, step 0.1°). Slider changes preview mesh in real-time (euler → axis-angle → temporary param update → viewport refresh). Apply button commits correction as PoseCorrection keyframe to CorrectionTrack. Reset joint / reset all buttons. Reference: `pose_correction_panel.py:on_joint_dropdown_change`, `on_euler_change`, `on_apply_correction`, `_get_joint_euler`. Backend: `pose_correction.py:axis_angle_to_euler_deg`, `euler_deg_to_axis_angle`.
- [ ] Quick-fix buttons + corrections table: flip body (180° rotation dialog), invert upright (flip global_orient about X/Z), mirror L/R (swap joint pairs), copy from frame (source frame dialog). Corrections table (QTableWidget: Frame, Type, Joint, Go/Delete). Reference: `pose_correction_panel.py:on_flip_whole_body`, `on_invert_upright`, `on_mirror_lr`, `on_copy_from_frame`, `_corrections_dataframe`. Backend: `pose_correction.py:flip_global_orient`, `mirror_lr_pose`, `copy_pose_from_frame`.
- [ ] Space overrides + BVH/FBX export: space override table (QTableWidget: Start, End, Space, Reference Person) with add/delete. Re-export BVH button applies all corrections via CorrectionTrack and exports. Re-export FBX button runs Blender subprocess conversion. Reference: `pose_correction_panel.py:on_add_space_override`, `on_delete_space_override`, `on_reexport_bvh`, `on_reexport_fbx`. Backend: `pose_correction.py:FrameSpaceOverride`, `smplx_to_bvh.py:convert_smplx_to_bvh`.
